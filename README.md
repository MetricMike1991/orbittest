# orbittest

## CodePen-like Template

This repository contains a basic CodePen-like setup with three template files:

### Files

- **index.html** - Main HTML template file with basic structure
- **style.css** - CSS template file with modern styling
- **script.js** - JavaScript template file with interactive functionality

### How to Use

1. Clone this repository:
   ```bash
   git clone https://github.com/MetricMike1991/orbittest.git
   cd orbittest
   ```

2. Open `index.html` in your web browser:
   - Double-click the file, or
   - Right-click and select "Open with" your preferred browser, or
   - Use a local development server

3. Start editing the files:
   - Modify `index.html` for your HTML structure
   - Edit `style.css` for your styles
   - Update `script.js` for your JavaScript logic

### Features

- Responsive design with modern CSS
- Interactive button with click counter
- Clean, organized file structure
- Ready to use as a starting point for web projects

### Quick Start Example

The template includes a simple interactive example:
- A styled container with a gradient background
- A button that counts clicks
- Random color changes on each click
- Console logging for debugging

Feel free to use this as a template for your own CodePen-like projects!
